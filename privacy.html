Политика конфиденциальности приложения «ПОМНЮ»

Редакция от 28 сентября 2026 года

Настоящая Политика описывает обработку данных мобильным приложением «ПОМНЮ» (ru.pomniu.app), цели обработки и доступные пользователю способы управления данными.

1. Разработчик и контакты

Разработчик и правообладатель: ИП Вавилова Елена Михайловна.

Контакт по вопросам конфиденциальности и работы приложения: alionkaj@gmail.com.

2. Какие данные может обрабатывать приложение

В зависимости от функций, которыми пользуется пользователь, приложение может обрабатывать:

  • текст напоминаний, даты и время, повторы, важность, состояние выполнения, ссылки и другие параметры напоминаний;
  • данные календаря Android при предоставлении разрешения: список доступных календарей и события, необходимые для выбранных пользователем операций импорта, резервного копирования и восстановления;
  • текст и ссылки, которые пользователь сам передаёт в ПОМНЮ через системную функцию «Поделиться»;
  • результат голосового распознавания при использовании диктовки;
  • при использовании «Близких»: имя профиля, созданные приложением идентификаторы пользователя, группы и устройства, отправленные близким напоминания и их время, статусы доставки и выполнения, причина отклонения, если пользователь её указывает, а также технические данные, необходимые для синхронизации и доставки push-уведомлений.

3. Локальное хранение

Личные напоминания и настройки хранятся в закрытом хранилище приложения на устройстве. Системное резервное копирование данных приложения Android отключено. Удаление приложения или очистка его данных средствами Android удаляет локальную копию данных в соответствии с поведением операционной системы.

4. Голосовой ввод

Для диктовки ПОМНЮ использует доступную на устройстве системную службу распознавания речи. В зависимости от выбранной службы аудиоданные могут обрабатываться её поставщиком по его условиям и политике конфиденциальности. ПОМНЮ не сохраняет отдельный аудиофайл записи голоса.

5. Календарь и резервная копия

Доступ к календарю предоставляется только после системного разрешения Android. При использовании резервной копии ПОМНЮ создаёт или обновляет события в выделенном календаре «ПОМНЮ»/«POMNIU» и может читать эти события для восстановления. Если пользователь выбирает календарь, синхронизируемый с аккаунтом Google или другим поставщиком календаря, данные резервной копии могут передаваться этому поставщику средствами Android и его службы синхронизации. Такая передача зависит от выбора и настроек пользователя.

6. «Близкие»

Если функция «Близкие» доступна в установленной версии и пользователь её включает, для синхронизации между участниками используются серверные сервисы ПОМНЮ. На сервер передаются только данные, необходимые для этой функции. Личные напоминания, которые пользователь не отправлял близким, не передаются в «Близкие».

Чувствительные поля данных «Близких» защищаются шифрованием при серверном хранении; сетевое взаимодействие production-версии должно выполняться по HTTPS. Данные не используются для рекламы, профилирования или продажи.

7. Push-уведомления

Для доставки событий «Близких» приложение может использовать RuStore Push. Для этого обрабатывается технический push-токен устройства и данные, необходимые для доставки уведомления. Содержимое личных напоминаний, не отправленных через «Близкие», для этой цели не требуется.

8. Разрешения Android

Приложение может запрашивать разрешения на уведомления, точные будильники, микрофон, чтение и запись календаря. Также используются системные возможности вибрации, восстановления расписания после перезагрузки, сетевого доступа и фонового выполнения, необходимые для напоминаний, синхронизации и push. Разрешения запрашиваются для соответствующих функций; пользователь может отказать в необязательном разрешении или отозвать его в настройках Android.

9. Передача третьим лицам

ПОМНЮ не продаёт пользовательские данные и не использует рекламные или аналитические SDK. Передача данных может происходить поставщику системного распознавания речи, поставщику выбранного пользователем синхронизируемого календаря и инфраструктуре RuStore Push в объёме, необходимом для соответствующей функции. При открытии внешней ссылки управление передаётся выбранному пользователем или системой приложению.

10. Управление и удаление данных

Пользователь может удалять напоминания внутри приложения и очищать локальные данные средствами Android. Для серверных данных «Близких», когда эта функция доступна, пользователь может прекратить использование функции; запрос по вопросам удаления серверных данных можно направить на alionkaj@gmail.com. Порядок удаления будет выполняться с учётом технически необходимых сроков резервного хранения и требований законодательства.

11. Платные функции

Если в версии приложения доступна подписка ПОМНЮ+, сведения о покупке и статусе подписки обрабатываются через платёжную инфраструктуру RuStore и используются для предоставления оплаченного доступа. ПОМНЮ не получает данные банковской карты пользователя.

12. Данные детей

Приложение не предназначено для целевого сбора персональных данных детей и не использует рекламу или рекламное профилирование.

13. Безопасность

Приложение ограничивает доступ к локальным данным средствами Android, не разрешает собственный незашифрованный HTTP-трафик в production-конфигурации и применяет меры защиты серверных данных «Близких» при включении этой функции.

14. Изменения Политики

Политика может обновляться при изменении функций, способов обработки данных или требований законодательства. Актуальная редакция публикуется по этому же адресу.

15. Обращения
