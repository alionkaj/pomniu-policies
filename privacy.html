Политика конфиденциальности приложения «ПОМНЮ»

Редакция от 30 августа 2026 года

Настоящая Политика конфиденциальности описывает, какие данные используются мобильным приложением «ПОМНЮ», для чего они нужны и как пользователь может ими управлять.

1. Разработчик и контакты

Разработчик приложения: Вавилова Елена Михайловна.

Контакт по вопросам конфиденциальности и работы приложения: alionkaj@gmail.com.

2. Какие данные использует приложение

В зависимости от используемых функций приложение может обрабатывать на устройстве пользователя:

  • текст напоминаний, даты, время, параметры повторов, важности и другие настройки напоминаний;
  • события системного календаря — только при ручном запуске импорта и после предоставления соответствующего разрешения;
  • текст и ссылки, которыми пользователь самостоятельно делится с приложением через системную функцию «Поделиться»;
  • распознанный текст голосового ввода при использовании функции диктовки.

3. Хранение данных

Напоминания, импортированные данные календаря и настройки приложения хранятся локально на устройстве пользователя. В текущей версии «ПОМНЮ» не использует собственный сервер для загрузки этих данных и не содержит рекламных или аналитических SDK.

Для данных приложения отключено системное облачное резервное копирование Android и перенос данных приложения между устройствами.

4. Голосовой ввод

Для диктовки приложение использует установленную на устройстве системную службу распознавания речи. В зависимости от выбранной пользователем или производителем устройства службы аудиоданные могут обрабатываться её поставщиком в соответствии с его собственными условиями и политикой конфиденциальности. «ПОМНЮ» не сохраняет отдельную копию аудиозаписи как пользовательский аудиофайл.

5. Разрешения Android

Для отдельных функций приложение может запрашивать:

  • разрешение на уведомления — для показа созданных пользователем напоминаний;
  • доступ к точным будильникам/напоминаниям — для срабатывания в выбранное время;
  • доступ к микрофону — только для голосового ввода;
  • доступ на чтение календаря — только для ручного импорта выбранных событий;
  • системные возможности восстановления уведомлений после перезагрузки и вибрации уведомлений.

Разрешения используются только для функций, которым они необходимы. Необязательные разрешения можно не предоставлять или отозвать в настройках Android.

6. Передача данных третьим лицам

Разработчик не передаёт содержимое напоминаний на собственные серверы и не использует его для рекламы или аналитики. При использовании системной службы распознавания речи данные могут обрабатываться поставщиком этой службы. При открытии внешней ссылки приложение передаёт ссылку выбранному пользователем или системой приложению Android.

7. Управление и удаление данных

Пользователь может удалять отдельные напоминания внутри приложения. Все локальные данные приложения можно удалить через системную функцию очистки данных приложения Android либо удалив приложение с устройства.

8. Данные детей

Приложение не предназначено для целевого сбора персональных данных детей и не использует аккаунты, рекламу или профилирование пользователей.

9. Безопасность

Данные приложения хранятся в локальном хранилище приложения, доступ к которому ограничивается средствами операционной системы Android. Приложение не использует незашифрованный HTTP-трафик для собственных сетевых запросов.

10. Изменения Политики

Политика может обновляться при изменении функциональности приложения, способов обработки данных или требований законодательства. Актуальная редакция публикуется по тому же общедоступному адресу.
